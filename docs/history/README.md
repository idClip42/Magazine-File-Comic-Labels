# Historical documents

This folder preserves documents that explain how V2 was planned or what the original collection looked like. They are useful provenance, but are not the current operational source of truth.

- `LABEL-INVENTORY.md` is the original 89-label snapshot. Use `config/labels.json` for the current 115-label order and contents.
- `COLOR-CATEGORY-PROPOSAL.md` records the reasoning behind the seven family colors now represented in `config/categories.json`.
