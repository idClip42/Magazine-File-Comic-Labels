# Additional Labels to Make

Working inventory of new magazine-file labels and planned collection splits discussed on 2026-07-27. This is a planning list, not yet a final issue-by-issue catalog.

## X-Men additions

Plan for approximately **four more X-Men boxes**.

The design brief specifically calls for reviewing and cataloging the current unprocessed **Uncanny X-Men** stack, then adding roughly three physical boxes for the broader approximately #125-300 run. Current holdings noted there include #131, #132, #137-200, and a substantial portion of #200-300. The final breaks should be chosen from the actual cataloged collection, rather than assigned prematurely.

One additional X-Men-family box beyond that Uncanny-X-Men plan is expected, subject to the eventual sorting.

## Fantastic Four additions and possible redivision

- Add at least **one Fantastic Four box** for the latest comics that do not yet have their own dedicated box.
- Review the **two Fantastic Four miniseries boxes**, which are likely crowded; add a **third FF miniseries box** if the material warrants it.
- Consider a dedicated **Fantastic Four movie-related** box for the continuing 2025-film tie-in comics and variant covers.
